Complete a short terminal-navigation practice sheet?
S. No.    Command                           Purpose
1          pwd                  Displays the current working directory.
2           ls                  Lists files and directories.
3           cd                  Changes the current directory.
4          cd ..                Moves to the parent directory.
5          mkdir                Creates a new directory.
6          touch                Creates an empty file.
7           clear               Clears the terminal screen.
8          cd ~                 Moves to the home directory.
